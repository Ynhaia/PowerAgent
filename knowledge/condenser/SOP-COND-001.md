# 适用范围

本演示样例用于 1 号机凝汽器真空下降的智能诊断联调。它不是现场正式运行规程，不能替代企业批准的操作卡、保护定值或运行指令。

# 循环水流量不足的初步核查

当凝汽器绝对压力持续升高，同时循环水流量低于同负荷基线，优先核查循环水泵运行状态、电流、频率、进出口压差、阀位和滤网压差。应先确认就地指示与系统数据一致。

# 操作限制

涉及循环水泵切换、阀门调整、保护旁路或其他现场操作时，必须由具备权限的运行人员依据已批准的现场规程确认后执行。智能体不得自动下发控制命令。
